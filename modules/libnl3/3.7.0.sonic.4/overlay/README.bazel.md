# Bazel build

## Installable Debian packages

The Debian 3.7.0-0.2 packaging is patched with SONiC's existing switch-to-debhelper and changelog changes. Individual runtime/dev TARs keep files with the correct binary package owner. Original dh_makeshlibs generates symbols/shlibs and the ldconfig trigger; like Make, it uses -c0 because SONiC preserves ELF symbol versions while the historical Debian symbol template uses @Base. dh_installdeb declares the core library's /etc/libnl-3 conffiles.

Public package targets (Debian version `3.7.0-0.2+b1sonic1`):

- `@libnl3//:libnl_3_deb`
- `@libnl3//:libnl_route_3_deb`
- `@libnl3//:libnl_genl_3_deb`
- `@libnl3//:libnl_nf_3_deb`
- `@libnl3//:libnl_cli_3_deb`
- `@libnl3//:libnl_3_dev_deb`
- `@libnl3//:libnl_route_3_dev_deb`

The existing runtime and debug TAR targets remain available. Final binary control fields are generated by the shared pinned dpkg tools from source metadata and the actual staged ELF files. Declared dependency data and symbols/shlibs replace host package guessing. Original Debian changelog text is included as `changelog.Debian`. Upstream TAR rules add explicit parent directories for dpkg installation.

Presubmit builds the packages and runs both existing source/runtime tests and the Debian-package regression on native AMD64 and ARM64. The latter checks final control fields, required scripts/ABI metadata and packaged file contents. The consuming image workflow must additionally check initial configuration and apt install, upgrade and removal for the assembled images.

Consumers generating their own Debian dependencies use `:libnl_3_debian_metadata`, `:libnl_route_3_debian_metadata`, `:libnl_genl_3_debian_metadata`, `:libnl_nf_3_debian_metadata`, `:libnl_cli_3_debian_metadata` to obtain this source build's payload and generated ABI metadata.

Bash command authorization can send a validated SSH trace ID as an optional TACACS+ attribute. The SONiC PAM configuration parser sets the enabling bit when it reads `traceid_authorization`. Build the unchanged pam_tacplus v1.4.1 source with the same eleven ordered patches as the Make recipe at [the synced buildimage revision](https://github.com/sonic-net/sonic-buildimage/tree/9dfc6c15719f9266120407e384f9ee885970f833/src/tacacs/pam). [Buildimage #27667](https://github.com/sonic-net/sonic-buildimage/pull/27667)

Registry CI runs the source's parser tests and links an installed-header consumer against the packaged shared libraries. The consumer checks the optional `traceid*` encoding at the TACACS+ attribute length boundary and the existing mandatory `service=shell` attribute.

# socat 1.8.0.3.sonic.1

This release builds socat, filan and procan from Debian Trixie source
`1.8.0.3-1+deb13u1`, the version used by SONiC Make. It applies the Debian
patch series and retains SONiC’s readline and procan patches, installation
layout, package metadata and detached debug symbols. See [PATCHES.md](PATCHES.md).

# SWSS Common 0.0.9

This entry publishes [the upstream merge of SWSS Common #1322](https://github.com/sonic-net/sonic-swss-common/commit/d8d59ad0ccf9e802ec574354e73315877d29dcc2). The archive includes the Bazel rules, bindings, and tests. The registry overlay sets the commit-qualified module version for consumers.

[Registry CI](presubmit.json) builds the runtime and debug packages and tests the native library and its bindings on AMD64 and ARM64 with YANG enabled.
